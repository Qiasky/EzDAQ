# XPort 温湿度工具

Windows 桌面程序，供韩感 LH8950 / LHG8950 的经典 Lantronix XPort 模块使用。

双击 `bin/XPort温湿度工具.exe`，无需安装 Python。默认设备地址 `192.168.31.201`，TCP 端口 `10050`。本机打包目录 `release/xport-tool` 另保留交付产物。

完整的接线、网络配置、HEX 解读、两台设备区别、命令行采集与微信上云步骤见 [XPort 韩感温湿度传感器驱动详细使用说明](../../docs/XPort韩感温湿度传感器驱动使用说明.md)。

## 实时采集

1. 选择与模块相连的电脑网卡，填写设备 IP 和端口。
2. 点 **开始采集**。默认发送后等待 10 秒，持续读取温湿度；点 **停止** 结束。
3. 界面显示通讯状态、最新温湿度、发送 HEX、接收 HEX 和最近 200 条通讯记录。

湿度原始值 `FFFF` 显示 **无效**，有效温度照常显示。连接失败、接收超时、LRC 错误会清空数值并显示错误，同时保留收到的部分 HEX。停止后保留最后一次结果，并明确标注已停止。

采集周期默认 10 秒；若等待与收取过程超过周期，将在完成后开始下一次。接收超时固定 10 秒。程序只读取本地传感器；现有微信云端采集进程独立运行。经典 XPort 可能只允许一个 TCP 客户端，同一模块采集时应关闭其他读取软件。

## 查找和修改 IP

1. 在 **查找 / 改 IP** 点 **查找 XPort**，核对列表中的 MAC 和设备标签。
2. 双击设备读取当前 IP、TCP 端口、掩码和网关。也可直接填写已知 MAC 与当前 IP，点 **读取选中设备**。
3. 填写新 IP / 掩码 / 网关，点 **保存新 IP**。端口不提供修改输入框，始终保留设备原值。
4. 模块保存后会短暂重启；如果改变了网段，将模块接回路由器并选择对应电脑网卡，再查找 / 读取核对。点 **用于实时采集** 可将已读取的 IP、端口带入采集页。

工具写入前重新读取并核对 MAC，备份完整配置；只修改 IP、子网掩码和网关字节，其余端口、串口及管理配置保持原值。未收到写入确认时显示待核对，先查找设备，避免重复写入。

跨网段的模块：先选择有线网卡查找。如电脑已安装 Wireshark / Npcap，工具会同时监听 6 秒 ARP，识别 `00:20:4A` 模块主动发出的地址；没有报文时可在查找期间重新上电。ARP 候选仍需用完整 MAC 与配置核对。未安装 Wireshark 时仍可通过 XPort UDP 广播查找，不会自动安装抓包驱动。

读取 / 修改要求电脑网卡与模块当前 IP 在同一网段；不满足时程序会阻止请求，点击 **网段帮助** 可复制临时电脑 IP 设置命令。该命令需在管理员 PowerShell 手动运行。改完后按实际需要恢复电脑网卡原设置；原来使用 DHCP 时帮助窗口提供恢复命令。

配置及备份保存在 `%LOCALAPPDATA%\EzDAQ\XPortTool`。备份含设备管理配置，请留在本地。实时 HEX 仅显示传感器收发，不显示完整管理记录。

## 协议和已验证设备

- TCP 发送 ASCII：`:000450000008A4\r\n`（17 字节）。
- 默认读取 27 字节，校验冒号、CRLF、功能码 `04`、数据长度和 LRC。
- 温度取响应 ASCII 字符偏移 11 的 4 位 HEX：`(word & 0x07FF) × 0.0625℃`。
- 湿度取字符偏移 15 的 4 位 HEX：`word ÷ 10 %RH`；`FFFF` 为已确认的无效标记。
- 原 LabVIEW 截图未包含负温真分支，负温标记显示解析错误并保留 HEX。
- 已核对 `00:20:4A:B9:93:F7`：新 IP `192.168.31.201`，端口 `10050`，掩码 `255.255.255.0`，网关 `192.168.31.1`。

网络配置按 Lantronix 的 [UDP 配置记录说明（附录 B）](https://www.lantronix.com/wp-content/uploads/pdf/XPress-DR_User_Guide.pdf)实现。适用于已实测的经典 XPort CoBos 30 字节固件响应 / 120 字节配置记录；其他型号或受限配置口会显示不支持 / 读取失败，不强行修改。

## 源码运行、测试与打包

```powershell
python apps/xport-tool/app.py
python -m unittest discover -s apps/xport-tool/tests -v
powershell -NoProfile -ExecutionPolicy Bypass -File apps/xport-tool/build.ps1
```

源码只依赖 Python 标准库与 Tk；打包使用独立 `.build/venv` 内的 PyInstaller。运行程序和打包默认无需管理员权限；临时修改电脑网卡才需要管理员权限。
