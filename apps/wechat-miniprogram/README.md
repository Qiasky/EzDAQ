# EzDAQ EPS 微信设备巡检小程序

原生微信小程序，可直接导入微信开发者工具。基于交接工程继续开发，沿用原 AppID 与云环境，纳入 EzDAQ 仓库统一维护。

## 交付入口

在微信开发者工具点击「导入」，目录选择：

```text
D:\Project\2026\EzDAQ\apps\wechat-miniprogram
```

选择这一层，不要选择 `miniprogram/` 子目录。AppID 已配置，不需要重新填写。

默认是**演示模式**，没有后台也能验收界面；每页右上角会显示「演示数据」。演示告警处置保存在内存，重启后恢复，可在「我的 → 恢复演示数据」重置。

## 已完成

- 设备总览：在线率、异常与离线统计，设备搜索、区域筛选、状态筛选，下拉刷新。
- 扫码入口：支持原始设备编号、`scene`、含 `deviceId` 的普通二维码链接与扫码返回的页面路径。
- 告警中心：按状态/级别筛选，分页、认领、填写处理说明后闭环；处理人员、时间、说明可查看。
- 设备详情：实时监控点、档案、最近告警、分享设备页、可切换监控点的趋势图。
- 我的：数据连接配置、连接测试、扫码、会话重置、说明、演示重置。
- 三种数据源：演示、微信云开发、仓库现有 EzDAQ 中心平台接口。真实连接失败会显示错误，绝不自动替换为演示数据。

物理设备状态由采集数据决定。处理完告警不会把仍异常的设备显示为正常。离线设备会提示实时值过期。

## 微信云开发联调

现有配置：

| 项目 | 位置 |
| --- | --- |
| AppID | `project.config.json`，沿用交接项目 |
| 云环境 ID | `miniprogram/config.js` 的 `ENV_LIST[0]`，沿用交接项目 |

具体步骤见 [部署手册](./部署手册.md)。完成后进入「我的 → 数据连接 → 微信云开发 → 测试连接 → 保存连接」，返回总览。无需自己编写接口。

小程序对应云函数已经在工程中：`login`、`deviceList`、`deviceDetail`、`alarmList`、`alarmHandle`、`deviceReport`。新版列表/详情会返回协议与处理说明；`alarmHandle` 校验闭环说明，并以旧状态为条件更新，避免两人同时覆盖。

首次云登录账户是 `viewer`。需要处置告警时，在云数据库 `users` 中把该账户的 `role` 设为 `operator` 或 `admin`；后端校验角色，前端不能自行提升权限。当前交接后台仍是单现场 MVP，未实现班组/站点隔离。

## 接入仓库 EzDAQ 平台（可选）

先运行中心服务：

```powershell
cd D:\Project\2026\EzDAQ\apps\center-platform
npm.cmd start
```

开发者工具里选择「我的 → 数据连接 → EzDAQ 平台」，地址填 `http://127.0.0.1:18080`。本地调试需在开发者工具「详情 → 本地设置」开启不校验合法域名；只用于开发工具本地调试。

手机不能用开发电脑的 `127.0.0.1`。正式连接需可访问的 HTTPS 地址及小程序 request 合法域名。当前中心服务是已有的无鉴权 MVP，客户端支持传入会话 Bearer Token；后端正式身份/站点授权需由平台提供。

适配的实际接口：

| 接口 | 用途 |
| --- | --- |
| `GET /api/health` | 测试连接 |
| `GET /api/dashboard`、`GET /api/devices` | 总览及设备详情 |
| `GET /api/alerts` | 告警筛选、分页与设备告警 |
| `POST /api/alerts/:id/ack`、`POST /api/alerts/:id/close` | 认领、闭环及备注 |
| `GET /api/history` | 当前平台模拟温度历史，仅用于 `temp-01` |

## 趋势数据边界

- 演示模式：明确标注为「24 小时演示趋势」。
- 微信云开发：现有交接云函数不存历史采样，因此显示「暂无历史采样」，不会生成假历史曲线。
- 当前 EzDAQ 中心：历史接口本身生成模拟温度趋势，页面标注「平台模拟温度趋势」，其他设备显示接口尚未提供历史。

## 开发与验证

不需要安装小程序前端依赖。

```powershell
cd D:\Project\2026\EzDAQ\apps\wechat-miniprogram
npm.cmd run check       # JSON、路由、组件、共享库、图标、JS 语法
npm.cmd test            # 业务流程、请求重试、筛选竞态、分页失败、真实平台接口联调
npm.cmd run test:gateway # 8950 报文解析、TCP 分包、错误帧与上报测试
npm.cmd run discover:xport -- --interface 192.168.31.122 # 本机家庭网卡 IP，Lantronix 官方搜索工具
npm.cmd run package     # 生成交付包，排除设备私钥与本地配置
npm.cmd run sync        # 修改 shared-lib 或种子数据后运行
npm.cmd run check:native # 调用本机微信开发者工具 wcc/wcsc
npm.cmd run preview     # http://127.0.0.1:18081
```

浏览器预览复用实际页面 WXML、WXSS、Page JS 与服务层；扫码用输入设备编号模拟。微信身份、真实扫码/分享及云函数运行请在开发者工具或真机验证。

Windows PowerShell 使用 `npm.cmd`，可避免 `npm.ps1` 被系统执行策略拦截，无需修改执行策略。

预览中的 EzDAQ 模式使用独立的临时中心平台数据，界面测试不会更改现有中心平台数据。预览仅监听本机，输入远程地址不会从浏览器预览发往远程平台。
