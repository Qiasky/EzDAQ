# EzDAQ

EzDAQ is Environmental Parameter Monitoring System（环境参数监控系统）。

EzDAQ 是面向机房与现场设备的数据采集、状态监控和巡检项目。通过现场采集程序连接传感器，将真实数据送到平台，供电脑和微信小程序查看，并完成告警认领、处理和闭环。

当前已打通韩感 LH8950 / LHG8950 的 **XPort TCP 采集 → 微信云开发 → 手机微信查看**，并提供可直接运行的 Windows 工具，用于查找模块 IP / MAC / 端口、修改 IP、实时显示温湿度与收发 HEX。

## 当前组成

- **现场采集**：Python TCP 驱动，校验原始帧、解析温湿度、签名上报。
- **Windows 工具**：Python / Tkinter，查找和配置 XPort、实时读数及通讯诊断。
- **移动巡检**：原生微信小程序 + 微信云开发，设备总览、搜索 / 筛选、扫码详情及告警处置。
- **Web MVP**：Node.js 中心 HTTP 服务与浏览器控制台，用于本地运行和接口联调。

项目处于 MVP 联调阶段。真实温度采集与手机显示已验证；本次探头湿度返回 `FFFF`，界面按无效数据处理。当前微信云端未保存历史采样，多站点隔离、完整通知渠道及更多工业协议适配属于后续扩展。

设备密钥、本地台账、管理配置备份、日志和构建环境不纳入 Git。换电脑后，桌面程序可直接使用，上云采集须重新准备本地配置与云端设备台账。
