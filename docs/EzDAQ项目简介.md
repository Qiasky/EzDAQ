# EzDAQ 项目简介

## 一句话描述

EzDAQ 是面向机房与现场设备的数据采集和移动巡检项目，支持传感器实时读数、设备状态监控，以及告警认领、处理和闭环。

## 简短介绍

EzDAQ 将现场传感器与设备采集程序连接起来，把实时数据送到平台，供运维人员通过电脑或微信小程序查看。项目以设备状态和异常处理为核心，覆盖设备总览、监控点查看、扫码定位、告警认领及处理记录，适用于机房环境监测、分散设备巡检和小型现场联调。

目前已完成韩感 LH8950 / LHG8950 温湿度传感器的真实接入：通过 XPort TCP/IP 读取原始报文，解析温湿度并经 HTTPS 上报微信云开发，手机微信可以查看实际温度。配套 Windows 工具支持查找模块 IP、MAC 与端口，保留端口修改 IP，并实时显示温湿度、通讯状态和收发 HEX，方便后续设备维护。

## 当前功能

- 设备总览、在线 / 离线状态、区域与状态筛选、设备搜索。
- 实时监控点、设备档案、扫码进入设备详情。
- 告警分级、认领、处理说明及闭环记录。
- XPort 模块查找、IP 配置与原始通讯诊断。
- Python 采集驱动、签名上报、微信云端数据读取。

## 技术组成与阶段

当前实现使用 Python / Tkinter 现场驱动与 Windows 工具、原生微信小程序、微信云开发，以及 Node.js Web MVP。设计文档中的完整企业平台架构属于后续演进方案。

项目处于 MVP 联调阶段，真实温度采集、上云及手机显示已经验证；当前探头湿度无效时如实标记。多站点权限隔离、云端历史采样、完整通知渠道及更多设备协议仍需扩展。
